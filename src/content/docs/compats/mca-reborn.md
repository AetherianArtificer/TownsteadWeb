**Install on:** The server and every client

Townstead is an addon for MCA Reborn. It does not load without MCA Reborn.

## What Townstead Builds On

- **Villagers.** Townstead adds needs, careers, Roots, cultures, conversations, reactions, and hangouts to MCA villagers.
- **Villages and buildings.** Townstead adds building types to the MCA Blueprint, and uses the buildings that MCA finds as workplaces, homes, and venues.
- **Families.** Townstead uses the MCA family tree for inheritance of Roots and genes.
- **Players.** Townstead gives players the same systems as villagers.

## Version

Each Townstead release supports exactly one MCA Reborn release. Install the MCA Reborn version that the Townstead release names. With another version, the game does not start.
