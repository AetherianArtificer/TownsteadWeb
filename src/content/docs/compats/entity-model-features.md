**Install on:** The client of each player who wants it

## What It Adds

- **Player animation packs.** A resource pack that animates the player model with Entity Model Features also animates MCA villagers and players drawn with an MCA model.
- **Emotes and Townstead animations.** While an emote or a Townstead animation plays, Entity Model Features draws the plain model, so the emote, its limb bend, and the Townstead animation show. After it ends, the pack's model comes back.
